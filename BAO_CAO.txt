1. NỀN TẢNG CSDL (PostgreSQL + RLS)
────────────────────────────────────────
Schema: 15 bảng
  Nền tảng: users, tenants, plans, password_reset_tokens
  Danh mục: properties, rooms, contracts, meter_readings, services
  Tài chính: invoices, invoice_line_items, payments
  Khác: notifications, audit_logs, support_requests

Row-Level Security:
  - Mọi bảng có tenant_id: ENABLE + FORCE RLS
  - Policy PERMISSIVE (tenant_isolation_policy): cô lập giữa các Tenant
  - Policy RESTRICTIVE (renter_restrictive_policy): Renter chỉ thấy dữ liệu
    liên quan đến hợp đồng của mình (11 bảng: users, rooms, properties, services,
    contracts, meter_readings, invoices, invoice_line_items, payments,
    support_requests, notifications)

3 vai trò CSDL:
  - owner: chỉ chạy migration/seed (BYPASSRLS)
  - app_user: nghiệp vụ, bị RLS cưỡng chế
  - app_system: auth/webhook/seed, BYPASSRLS

Partial unique indexes:
  - uq_contract_active_room: 1 hợp đồng ACTIVE/phòng
  - uq_room_property_code, uq_service_property_name, uq_meter_room_month

  20261015000001_renter_rls_fix (ĐÃ DÙNG)
    - DROP và tạo lại: PERMISSIVE (tenant_isolation_policy) + RESTRICTIVE
      (renter_restrictive_policy) trên 11 bảng
    - renter_restrictive_policy: AS RESTRICTIVE FOR ALL (không phải FOR SELECT)
      Với FOR ALL, PostgreSQL áp dụng USING cho SELECT/UPDATE/DELETE và
      WITH CHECK (mặc định dùng lại USING) cho INSERT.

    - Landlord: thấy toàn bộ Tenant, INSERT/UPDATE/DELETE bình thường

3. MODULE AUTH (UC01, UC02, UC03, UC08-11, UC24-26)
────────────────────────────────────────
  Đăng ký Landlord (UC08):
    - Tạo Tenant (gói mặc định + hạn dùng thử) + User LANDLORD trong MỘT transaction
    - Bắt lỗi P2002 khi email trùng đồng thời

  Đăng nhập (UC01, UC09, UC24):
    - Kiểm tra theo thứ tự: mật khẩu → tài khoản bị khóa → Tenant tạo ngưng (bỏ qua Admin)
    - Token JWT chứa userId, role, tenantId

  Middleware auth (src/middleware/auth.ts):
    - authenticateJwt: verify JWT → query DB lấy role, tenantId thực tế → gán req.user
      (không tin token)
    - requireRole: RBAC theo vai trò

  TenantGuard (src/middleware/tenantGuard.ts):
    - requireActiveSubscription: chặn TẠO MỚI khi Tenant hết hạn (Luật 12)
      Admin bị bỏ qua; Tenant hết hạn vẫn đăng nhập và xem được
    - checkResourceLimit: kiểm tra maxProperties/maxRooms từ Plan
      Chặn tạo Property/Room khi vượt giới hạn gói

  Quên mật khẩu (UC02, UC10, UC25):
    - crypto.randomBytes(32), băm sha256, thông báo chung chống user enumeration
    - Token cũ bị vô hiệu khi có yêu cầu mới

  Bảo mật:
    - Không bao giờ trả passwordHash
    - Tránh timing attack khi email không tồn tại

4. MODULE ADMIN (UC04-07)
────────────────────────────────────────
  Tất cả route: authenticateJwt + requireRole(ADMIN) + prismaSystem (BYPASSRLS)

  UC04 — GET /api/admin/users
    - Phân trang (page, pageSize), filter: role, status, tenantId, search (tên/email)
    - PATCH /api/admin/users/:id/lock: khóa user (không khóa chính mình, không khóa Admin)
    - PATCH /api/admin/users/:id/unlock: mở khóa
    - Token cũ của user bị khóa bị từ chối ngay (middleware auth kiểm tra DB)

  UC05 — GET /api/admin/tenants
    - Phân trang, filter: status, search, subscriptionStatus (active/expiring_soon/expired)
    - GET /api/admin/tenants/:id: chi tiết + counts (users, properties, rooms)
    - PATCH /api/admin/tenants/:id/suspend: tạm ngưng (token Landlord/Renter bị 403 ngay)
    - PATCH /api/admin/tenants/:id/activate: kích hoạt lại
    - Không có API tạo Tenant thủ công

  UC06 — GET /api/admin/plans
    - POST /api/admin/plans: tạo gói (maxProperties, maxRooms, price, durationDays)
    - PATCH /api/admin/plans/:id: sửa gói
    - PATCH /api/admin/plans/:id/deactivate: ẩn gói (is_active=false, không xóa cứng)
      Từ chối: gói mặc định (DEFAULT_PLAN_NAME), gói đang có Tenant sử dụng

  UC07 — PATCH /api/admin/tenants/:id/plan
    - Đổi gói + extendDays (tính từ subscriptionEnd hiện tại hoặc now)
    - Hoặc đặt subscriptionEnd trực tiếp
    - Từ chối gói đã ẩn
    - Nếu giới hạn gói mới nhỏ hơn số lượng hiện có: vẫn cho đổi, trả warnings[]

  Bảo mật:
    - Response không chứa passwordHash, nationalId
    - Select tường minh (không dùng include cho user)
